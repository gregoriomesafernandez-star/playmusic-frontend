# Music Management App (Angular)

Frontend application developed with Angular for a music management and playback platform.

The application allows users to manage artists, albums and songs, with JWT authentication and role-based access control. It is connected to a Node.js and Express REST API with MongoDB.

## Backend Repository

[Musicfy Backend](https://github.com/gregoriomesafernandez-star/playMusic-backend)

## Features

- User registration
- User login with JWT authentication
- User profile management
- Artist management
- Album management
- Song management
- Image upload
- Audio file upload
- Music playback
- Role-based access control
- Form validation
- Responsive design
- Integration with Node.js REST API

## Technologies

- Angular 21
- TypeScript
- RxJS
- Angular Router
- Angular Forms
- Tailwind CSS 4
- PostCSS
- HTML5
- CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/gregoriomesafernandez-star/playMusic-frontend.git
cd musicfy-frontend
```

Install dependencies:

```bash
npm install
```

## Backend API

This application requires the Musicfy backend to be running.

Clone and configure the backend repository following its README instructions.

The backend API runs by default at:

```text
http://localhost:3000
```

Make sure MongoDB is running and the backend is started before using the application.

## Start the Development Server

Run:

```bash
ng serve
```

Open your browser at:

```text
http://localhost:4200
```

## Application Routes

| Route | Description |
|---|---|
| `/` | Redirects to the home page |
| `/home` | Home page |
| `/user-edit` | Edit user profile |
| `/artist/create` | Create an artist |
| `/artists/:page` | List artists |
| `/artist/edit/:id` | Edit an artist |
| `/artist/detail/:id` | View artist details |
| `/album/list` | List albums |
| `/album/create/:artistId` | Create an album for an artist |
| `/album/edit/:id` | Edit an album |
| `/album/detail/:id` | View album details |
| `/song/list` | List songs |
| `/song/create/:albumId` | Create a song for an album |
| `/song/edit/:id` | Edit a song |

## Authentication

User authentication is handled through JWT tokens generated by the Node.js API.

The application uses role-based access control to restrict administrative operations such as creating, editing and deleting music content.

## Music Management

Artists can have multiple albums, and each album can contain multiple songs.

Images and audio files are uploaded through the application and managed by the backend.
